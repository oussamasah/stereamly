# Sprint 0 — Cadrage légal, produit et architecture

## Statut

**Terminé — version validée 1.0 — 7 septembre 2026**

Ce dossier contient les livrables nécessaires avant le développement du socle technique. Les décisions inconnues sont marquées **À valider**. Elles doivent être confirmées par le propriétaire du projet et, pour les aspects juridiques ou fiscaux, par un professionnel compétent.

## Objectif du sprint

Valider que le service peut être vendu et diffusé légalement, définir précisément le MVP et figer les choix métier et techniques qui structurent les prochains sprints.

## Conditions de sortie du sprint

- La matrice contient toutes les chaînes prévues au lancement et aucune ligne obligatoire n’est vide.
- Une preuve contractuelle valide existe pour chaque combinaison chaîne/territoire/appareil commercialisée.
- Les prix, durées, devises, limites d’appareils et connexions sont approuvés.
- Le prestataire de paiement et les règles de remboursement sont choisis.
- Les parcours et états métier sont validés sans transition ambiguë.
- La stack, les environnements et le modèle de données sont approuvés.
- Chaque story MVP a une priorité, un propriétaire et un critère de réussite.

Le Sprint 0 est clôturé. L’identité légale, les taxes et les preuves de droits des chaînes tierces restent des **portes de mise en production**, mais ne bloquent pas le développement avec contenu synthétique et paiement simulé.
